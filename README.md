# Time Share Radio

Astro presentation and storefront for [timeshareradio.net](https://timeshareradio.net).

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

Cloudflare Pages settings:

- Framework preset: `Astro`
- Build command: `npm run build`
- Build output directory: `dist`
- Node.js version: `22` or newer
